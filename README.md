# realeatate-researcher — 유사입지 기반 상가 활용 추천 (MVP 1단계)

"내 상가와 **입지 조건이 비슷한 다른 상가들**을 찾아, 거기선 실제로 어떤 업종이
성업 중인지 역추적해 **상가 활용 방안을 추천**"하는 파이프라인의 1단계 뼈대입니다.

- **공공데이터만으로** 돌아가도록 설계 (유동인구·카드매출 등 유료 데이터는 2단계).
- **API 키 없이 `--demo`** 로 전 과정을 즉시 검증 가능 (합성 데이터 생성기 내장).
- 실데이터 연동부는 **동일 스키마 stub** → 키 받으면 해당 부분만 채우면 됩니다.

## 빠른 시작

```bash
pip install -r requirements.txt

# 1) 합성 데이터 데모 (키 불필요) — 로직부터 검증
python scripts/run_mvp.py --demo

# 2) 좌표 지정
python scripts/run_mvp.py --demo --lat 37.5700 --lon 126.9820 --k 12 --top 8
```

## 파이프라인

```
수집(collect) → 피처화(features) → 유사입지 KNN(model) → 업종 추천(recommend)
```

| 단계 | 모듈 | 역할 |
|---|---|---|
| 수집 | `src/collect/sources.py` | 공공 API 연동(+`synthetic.py` 폴백) |
| 피처화 | `src/features/build_features.py` | 반경 내 인구·교통·경쟁·업종구성을 벡터로 |
| 모델 | `src/model/similarity.py` | 표준화 + KNN 으로 유사입지 탐색 |
| 추천 | `src/recommend/recommend.py` | 유사입지의 성업 업종 집계 + 과밀 보정 |

입지 피처(8종): 인구수, 청년/고령 비중, 소득지수, 상가밀도, 업종다양성(엔트로피),
대중교통 접근성, 교통량 프록시 — 순서는 `FEATURE_COLS` 에 고정.

## 실데이터로 전환하기

1. [`.env.example`](.env.example) 의 링크에서 키 발급 → `.env` 로 복사해 값 입력
   - 소상공인 상가(상권)정보 / 지방행정 인허가 / 통계청 SGIS
2. `src/collect/sources.py` 의 `TODO` 부분(API 응답 → 내부 스키마 매핑)만 구현
3. `--demo` 없이 실행하면 자동으로 실 API 경로 사용

## 한계 & 2단계 로드맵

- **생존기간을 성공 대리지표로 사용** → 2단계에서 카드매출/유동인구로 보강
- 후보 입지 = 기존 상가 위치 → 격자/필지 단위로 확장 가능
- KNN(해석가능) → 데이터 커지면 임베딩/학습형 모델로 교체
- 시각화(지도)·웹 서비스화(FastAPI+React)는 MVP 검증 이후
